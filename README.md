# 건강 밸런스 레이스 v19 — 교사용 + 학생용 실시간 7인 수업

v18의 화면·달리기·아이템·속도 규칙을 바탕으로 실제 수업용 서버를 추가한 패키지입니다.

## 작동 방식

- **교사**: `/teacher` 접속 → **새 게임방 만들기** → QR 표시 → 참가 명단(최대 7명) 확인 → **전체 게임 시작** → 모든 선수 완주 → **최종 순위 공개**
- **학생**: 교사의 QR 스캔 → `/play?room=게임방코드` 접속 → 닉네임·색상 입력 → 대기실 → 교사의 시작 명령 이후 출발 → 레이스 완주 후 결과 공개 대기 → 교사가 공개하면 순위·밀리초 기록 확인
- 학생은 Wi-Fi, LTE, 5G 등 **서로 다른 인터넷 연결**에서 접속할 수 있습니다. QR에 담기는 것은 공개 웹사이트 주소입니다.
- 새로고침을 해도 같은 브라우저에 저장된 참가 토큰으로 기존 선수에 복귀합니다.
- **실제 학생 최대 7명**끼리 경쟁합니다. 가상 선수는 없습니다.

## 배포 방법: GitHub → Render

1. ZIP 파일을 풀고 프로젝트의 **모든 파일**(특히 `server.py`, `requirements.txt`, `render.yaml`, `public/`)을 GitHub 저장소에 업로드합니다. 기존 저장소 `https://github.com/ttock3/whatheck`를 사용할 수 있습니다. 저장소의 기존 파일을 덮어쓰려면 변경 사항을 먼저 확인해 주세요.
2. [Render](https://dashboard.render.com/)에서 **New → Web Service**로 GitHub 저장소를 연결합니다. GitHub 연결이 아직 없다면 연결 승인 과정이 필요합니다.
3. 아래 설정을 사용합니다.

   | 설정 | 값 |
   |---|---|
   | Runtime | Python |
   | Region | Singapore |
   | Instance Type | Free (시험용) |
   | Build Command | `pip install -r requirements.txt` |
   | Start Command | `python server.py` |
   | Health Check Path | `/health` |

4. 배포가 완료되면 Render가 제공하는 `https://...onrender.com` **실제 주소**를 확인합니다. 이 주소는 Render에서 배포가 성공한 뒤에만 유효합니다.
5. 교사는 `https://...onrender.com/teacher`에 접속합니다. 교사용 비밀 토큰은 게임방 생성 때 발급되며 교사 브라우저의 **세션 저장소**에 저장됩니다. 학생에게는 참가 QR만 보여주세요.
6. 수업 5~10분 전에 교사 화면을 열어 Render 무료 서버가 기동했는지 확인한 다음, 휴대폰 한 대는 Wi-Fi, 다른 한 대는 모바일 데이터로 실제 접속을 시험해 보세요.

## 수업 시 유의점

- 실제 수업 전 **교사 1기기 + 학생 2기기 이상**에서 교사 시작, 레이스, 마지막 선수 완주, 최종 순위 공개까지 예행연습을 진행하세요.
- Free Render 웹 서비스는 약 **15분 무접속 시 절전**할 수 있고, 다시 켜지는 데 약 1분 걸릴 수 있습니다. 서버 재시작·재배포·절전 시 게임방과 학생 기록은 사라집니다. 수업 전 서버를 깨워 두세요.
- 7명이 모두 들어오지 않아도 교사가 테스트 목적으로 경기를 시작할 수 있습니다. 7명이 예정이면 학생 수를 확인하고 시작하세요.
- 게임에서 사용하는 에너지 수치는 **실제 kcal이나 체중 관리에 대한 의학적 계산이 아닌 수업용 모형 점수**입니다. 음식 하나를 무조건 좋다/나쁘다로 판단하는 규칙이 아님을 안내해 주세요.
- 실명 대신 닉네임을 사용하세요. 닉네임/진행 상태는 서버 메모리에만 저장하며 영구 보관하지 않습니다.
- 본 버전은 한 서버 인스턴스에서 동작하며 경기용입니다. 다수 교실의 동시 사용이나 높은 가용성을 보장하지 않습니다.

## 로컬 실행 (개발자용)

```bash
pip install -r requirements.txt
python server.py
```

기본 주소는 `http://localhost:10000/teacher`, 학생용 주소는 `http://localhost:10000/play`입니다. 로컬 주소는 같은 기기에서만 작동하므로 **다른 네트워크 접속 테스트는 배포한 공개 주소에서** 실시해야 합니다.

## 자동 검증

```bash
python -m unittest discover -s tests -v
```

테스트는 7명 제한, 닉네임 중복 방지, 속도 1.5/2/3배, 균형·일시 감속, 전원 완주 판정, 교사 공개 전 기록 비공개, 다음 라운드 초기화를 검사합니다.
